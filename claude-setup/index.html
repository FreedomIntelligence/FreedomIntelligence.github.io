Claude Code & Opus 5.5 SetupClaude Code 与 Opus 5.5 使用指南

A short setup reference for the AI project test.AI 项目测试的简短工具配置参考。

Install Claude Code on your computer, then connect it to a service that provides Opus 5.5. The model runs remotely; this does not install model weights locally. You may use other tools for the AI project test.在电脑上安装 Claude Code，再接入提供 Opus 5.5 的服务。模型在远端运行，不是将模型权重安装到本地。参加 AI 项目测试也可以使用其他工具。

Open third-party platform ↗前往第三方平台 ↗

1. Install Claude Code1. 安装 Claude Code

Follow the official installation guide. On Windows, open PowerShell and run:按官方安装说明操作。Windows 用户可打开 PowerShell，运行：

irm https://claude.ai/install.ps1 | iex

Alternatively, if you already use WorkBuddy, ask it to help install Claude Code from the official source. To prefer drive D, ask it to check installation, cache, and configuration locations; some files may still use drive C.如果已使用 WorkBuddy，也可以请它协助从官方来源安装 Claude Code。希望优先使用 D 盘时，让它检查安装、缓存和配置目录；部分文件仍可能占用 C 盘。

Open a new terminal and check:重新打开终端，检查是否安装成功：

claude --version

2. Configure access2. 配置服务接入

You can use official Claude access or choose a third-party service. For the latter, first confirm that it supports Claude Code and Opus 5.5, review its pricing, then create an API key in its console. Follow that provider's current instructions for the API base URL, authentication field, and model ID. The wallet page is not an API endpoint. We have not verified this provider's current configuration or model routing.可以使用 Claude 官方接入方式，也可自行选择第三方服务。使用第三方时，先确认其支持 Claude Code 和 Opus 5.5、了解计费方式，再按需开通并在控制台创建 API 密钥。API 地址、认证字段及模型 ID 均以服务商最新教程为准；钱包页面不是 API 接口地址。我们未核验该平台当前的配置及模型路由。

Ask WorkBuddy to locate the configuration file if needed, then enter the key locally. Do not put API keys in chat messages, screenshots, public repositories, or test submissions. Requests sent through a third party are handled by that provider.不清楚配置文件位置时，可请 WorkBuddy 协助定位，再自行在本地填写密钥。不要把 API 密钥放入聊天、截图、公开仓库或测试提交材料。通过第三方接入的请求会交由该服务商处理。

3. Start and select the model3. 启动并选择模型

Reopen the terminal, enter your project folder, and run:重新打开终端，进入项目目录后运行：

claude

Use /model to select Opus 5.5 when available. If a gateway requires a custom model ID, use the exact ID in its documentation. Check /status and run a small task to confirm access. A displayed model name alone does not verify a third party's actual backend.使用 /model，在可用选项中选择 Opus 5.5；网关需要自定义模型 ID 时，使用其文档给出的准确名称。通过 /status 检查配置，并用一个小任务验证接入。客户端显示的模型名称本身不能证明第三方实际调用的后端模型。
